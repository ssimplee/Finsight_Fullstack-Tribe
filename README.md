# Finsight_Fullstack-Tribe

FinSight is a multimodal fish-health diagnostic triage assistant for Nile tilapia in freshwater aquaculture.

## Repository Structure

```text
backend/   FastAPI API, case/session handling, integration points
frontend/  React/Next.js user interface
shared/    JSON schemas and example payloads shared by all members
data/      curated knowledge base, sources, images, and evaluation cases
docs/      API contract and architecture notes
infra/     deployment and environment setup
```

## Member 1 Focus

Member 1 owns the backend, shared API/data contract, integration structure, deployment setup, and final system wiring. This skeleton gives the rest of the team stable folders and filenames to work against.

## First Milestone

Build one complete working case end to end with mock data before expanding to all five conditions.
